## Ready-to-use project message

MergeProof is an open-source evidence-first multilingual GitHub contribution dossier. It converts real PR metadata into a compact source-of-truth packet and uses Apertus 1.5 to explain contribution evidence in English, German, French, and Russian. An independent validator rejects invented evidence references and prevents the model from changing real merge status. We evaluated a real locally hosted community Apertus v1.5 8B MLX model: 4/4 languages retained the correct MERGED state, with zero invalid evidence references accepted. The public demo accurately displays recorded, not live-hosted, model output. Sources, implementation, tests, and benchmark results are included in the repository.
